# LIMATA One-Click Furniture Store

## Project Proposal

# 1. Introduction

## 1.1 Title of the Project

LIMATA One-Click Furniture Store

## 1.2 Project Description

A web-based furniture e-commerce platform that digitizes a physical furniture business and introduces AI-assisted AR visualization, environmental analysis, and intelligent recommendations.

## 1.3 Background and Motivation

The project combines modern e-commerce with AR, AI, object detection, and depth estimation to improve furniture purchasing decisions.

## 1.4 Problem in Brief

- Limited reach of physical furniture stores
- Difficulty visualizing furniture in customer environments
- Reduced customer confidence before purchase

## 1.5 Proposed Solution

A centralized furniture e-commerce platform with:

- Product browsing and purchasing
- AI-assisted AR visualization
- YOLOv8 object detection
- MiDaS depth estimation
- Spatial suitability analysis
- Intelligent recommendations

## 1.6 Aim and Objectives

### Aim

Develop an AI-assisted spatial suitability analysis system using object detection and depth estimation techniques.

### Objectives

- Develop an online furniture e-commerce platform
- Integrate AI-assisted AR visualization
- Develop spatial suitability analysis
- Implement order and product management
